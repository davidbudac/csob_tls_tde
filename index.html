● Validated
The TDE SQL chain (01 → 02 → online encrypt → 04 → 05) and the TLS wallet script + TCPS config + verify SQL were run end-to-end on a 19.27 Linux CDB (2026-07-07). Key verified facts: FILE_NAME_CONVERT=NONE fails on OMF; the DB's sqlnet.ora needs WALLET_LOCATION for TCPS (else ORA-28865); only one WALLET_LOCATION is honored (SEPS conflict); CONTAINER=ALL rotation creates untagged keys. RU/AIX-specific items remain to confirm on the real fleet.
